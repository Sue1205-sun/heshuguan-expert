# 核数官 · WorkBuddy 专家包

一个核验优先的金融分析专家：每个数字都要找到第二个来源，找不到就标"存疑"；勾稽关系逐条检查，材料缺科目就写"未执行"，不当成通过。

## 评委安装（三步，约 1 分钟）

1. 打开 WorkBuddy，在**任意对话的输入框输入 `/plugins`**，打开插件管理
2. 点 **添加市场**，在"市场源"里填：
   ```
   Sue1205-sun/heshuguan-expert
   ```
   点提交
3. 在列表中找到 **核数官**，点 **安装**，再点 **启用**

装好后左侧 **专家 → 我的专家** 里出现「核数官」，点进去即可对话。

## 三种模式（直接打字，自动识别，不需要切换）

**A. 智能投研** —— 上传年报，出速读报告

```
这是伊利股份2024年年度报告，请出一份财报速读报告。
```

**B. 风控核验** —— 上传授信材料，出红旗清单

```
这是一份企业授信申请材料，帮我核验财务数据一致性，列出欺诈红旗，输出风险评分卡。
```

**C. 合规问答** —— 不传文件，纯文字提问

```
我们银行网点向老年客户推销理财产品，销售话术是保本保息、稳赚不赔，帮我核验这话术是否合规，并给出合规替代话术。
```

## 实测输出（可复现）

| 模式 | 输入 | 结果 |
|---|---|---|
| A | 伊利股份 2024 年报（270 页 PDF） | 关键指标三年对比 + 核验底稿 12 个数字逐个标页码；勾稽 3 项执行、5 项标注未执行；商誉减值 30.75 亿 |
| B | 某贸易公司授信材料（docx） | 高风险，命中 7 条红旗（5 条重红旗）；另 3 条因数据缺失无法判定，如实标注 |
| C | 一句销售话术 | 严重不合规，条款落到「条、款、项」，并给 6 个场景的可替换话术 |

## 确定性引擎

`plugins/heshuguan/skills/heshuguan-verify/scripts/` 下是纯标准库实现，不依赖任何第三方包：

在 `plugins/heshuguan/skills/heshuguan-verify/scripts/` 目录下执行：

```
python -m heshuguan check data/huachen.json
```

输出一份完整核验底稿（含全部算式与取数位置）；同样的输入永远得到同样的输出，可以交给第三方复算。测试用例 39 条。

## 设计原则

1. **缺失不补**：材料没给的科目，不做推算、不填默认值。
2. **除零返回 None**：分母为零时不输出 0，标为无法计算。
3. **证据不足不命中**：宁可少一条红旗，不凑数。
4. **结论可追溯**：每个数字标页码或接口字段，交给第三方能复算。
