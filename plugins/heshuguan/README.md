# 核数官 Heshuguan

面向小微金融场景的可核验金融分析专家。不做万能助手，只做一件事：核实。

## 类型

Agent 型（单个 AI 专家）

## 功能

核数官把审计行业的工作底稿方法论搬进金融分析：先核实，再判断，留证据。

**三种模式**

| 模式 | 触发 | 输出 |
|---|---|---|
| A 智能投研 | 分析上市公司年报 | 一页速读报告：关键指标三年对比表、三个变化点解读、风险提示、核验底稿 |
| B 风控核验 | 核验授信材料 | 风险评分卡、欺诈红旗清单（每条附判定依据） |
| C 合规问答 | 金融业务合规问题 | 结论、监管条款编号与原文、合规替代话术 |

三种模式共用一套流程，差别只在提取要素和输出格式。

**核验层做什么**

- 每个关键数字至少两个来源，不一致就标存疑并列出双方数值，不自行取舍
- 勾稽检查：利润与现金流方向、毛利率偏离、资产等于负债加权益、折旧与固定资产匹配
- 欺诈红旗：十条判定标准，证据不足时不命中，宁可少一条
- 全部数字附出处，末尾附核验底稿，未核实的结论无处隐藏

**确定性核算**

内置 `skills/heshuguan-verify`，纯 Python 标准库，把核验规则写成可运行代码。同一份材料，谁跑都是同一个结论，不依赖模型自觉。附 39 个回归用例，以及一个有问题样本和一个健康样本，用来验证引擎有判别力而不是见谁都报警。

## 使用示例

- 这是伊利股份2024年年度报告，请出一份财报速读报告。
- 这是一份企业授信申请材料，帮我核验财务数据一致性，列出欺诈红旗，输出风险评分卡。
- 我们银行网点向老年客户推销理财产品，销售话术是保本保息、稳赚不赔，帮我核验这话术是否合规，并给出合规替代话术。

## 目录结构

```
heshuguan/
├── .codebuddy-plugin/plugin.json   专家定义
├── agents/heshuguan.md             角色、工作流、输出规范、边界
├── avatars/expert.png              头像
└── skills/heshuguan-verify/
    ├── SKILL.md                    何时调用、怎么跑、五条实现原则
    ├── references/                 四份知识库：口径说明、报告模板、红旗清单、合规要点
    └── scripts/                    核验引擎与测试
```

## 头像

头像已自动生成在 `avatars/` 目录下。如需替换为自定义头像，要求：
- 格式：PNG（推荐）或 JPG
- 尺寸：512×512 px
- 大小：单张不超过 500KB

## 安装

将专家包目录放到专家目录下：

```
C:\Users\HUAWEI\.workbuddy\plugins\marketplaces\my-experts\plugins\heshuguan\
```

然后注册：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
python3 scripts/package_expert.py <expert-dir>
```
