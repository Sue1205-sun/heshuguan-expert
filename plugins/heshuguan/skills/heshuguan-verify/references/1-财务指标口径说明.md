# 财务指标口径说明（核数官知识库 V1）

> 本文件是"核数官"计算与分析财务指标的唯一口径依据。与通用算法冲突时，以本文件为准。

## 一、通用指标口径

### 1. 增长率
- 公式：（本期 − 基期）/ |基期| × 100%
- **基期为负数时**：必须使用绝对值作分母，并额外标注"基期为负，增长率参考意义有限"
- 基期为 0 或接近 0：增长率无意义，改用绝对增减额描述

### 2. 毛利率
- 公式：（营业收入 − 营业成本）/ 营业收入 × 100%
- 口径说明：使用利润表中的"营业收入"与"营业成本"科目；若财报附注披露口径有变（如会计政策变更、重述），须按可比口径重述并标注

### 3. 净利率
- 公式：归母净利润 / 营业收入 × 100%
- 注意区分"净利润"与"归母净利润"（扣少数股东权益），报告中默认使用归母口径

### 4. ROE（净资产收益率）
- 默认口径：归母净利润 / 平均归母净资产
- 平均净资产 =（期初 + 期末）/ 2
- 若引用摊薄口径须注明

### 5. 经营现金流
- 取现金流量表"经营活动产生的现金流量净额"
- **勾稽检查**：净利润为正而经营现金流连续两年为负 → 红旗（见红旗清单 F1）

### 6. 自由现金流（FCF）
- 简化口径：经营现金流净额 − 购建固定资产、无形资产和其他长期资产支付的现金
- 使用合并报表口径；如需股权口径（FCFE）须明确标注

## 二、金融行业专用口径

银行、保险等金融企业**不适用**上述一般企业模板：
- 银行：核心指标为净息差（NIM）、不良贷款率、拨备覆盖率、资本充足率；"营业收入"含利息净收入，毛利率指标不适用
- 保险：看新业务价值（NBV）、综合成本率、偿付能力充足率
- 券商：看经纪/投行/资管收入结构，市场敏感度高

## 三、合理区间参考（用于异常值预警）

| 指标 | 常见合理区间 | 预警信号 |
|---|---|---|
| 毛利率 | 与同行业均值偏差 ±10 个百分点以内 | 显著高于行业龙头仍"毛利率奇高+现金流差"组合 |
| 资产负债率 | 制造业 40%-65% | >80%（非金融、非地产） |
| 净利润与经营现金流比 | 经营现金流/净利润 长期 ≥0.8 | 长期 <0.5 |
| 应收账款增速 vs 营收增速 | 大体同步 | 应收增速持续远超营收增速 |

> 以上区间为通用经验参考，具体行业以知识库中行业资料为准；超出区间仅作"预警提示"，不直接下欺诈结论。

## 四、数据核对规则

1. 每个关键数字至少两源核对：财报原文 vs 联网检索（交易所公告、巨潮资讯、公司官网）
2. 两源不一致 → 标"⚠️存疑"，列出双方数值与出处，不自行取舍
3. 会计政策变更导致的口径变化 → 联网核实后按可比口径重述，并说明变更内容
4. 所有数字标注出处：年报页码 / 公告标题与日期 / 计算过程
