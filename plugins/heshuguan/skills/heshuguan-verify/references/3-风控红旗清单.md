# 财务欺诈红旗清单（模式B核验依据 V1）

> 模式B（风控核验）逐条检查本清单。每发现一条红旗，输出时必须附：触发的具体数据、计算过程、清单编号。红旗数量仅作风险分级参考，最终结论须综合判断，不得仅凭红旗下"欺诈"定性。

## 风险分级标准

- 0-1条红旗 → 低风险
- 2-3条 → 中风险（建议补充尽调）
- ≥4条或命中任一 ★重红旗 → 高风险（建议人工复核）

## 十条红旗

### F1 ★营收与现金流长期背离
净利润连续两年为正，经营现金流净额为负或长期低于净利润30%。利润"纸面富贵"，是最经典的造假信号。

### F2 ★应收账款异常膨胀
应收账款增速持续显著高于营收增速（如超出20个百分点以上），或应收账款/营收比例骤升。可能虚增收入或放宽信用粉饰报表。

### F3 毛利率显著偏离同行
毛利率远高于行业龙头且无合理解释，或毛利率异常稳定（在行业波动时纹丝不动）。需结合行业口径判断（见指标口径文件第三节）。

### F4 ★关联交易占比畸高
前五大客户/供应商中关联方销售采购占比过高，或交易定价明显偏离市场。虚增收入的常见通道。

### F5 存贷双高
账面货币资金充裕（数十亿级）却同时高额有息负债、利息费用不低。典型如康美、康得新案特征。存款真实性与受限情况须核实附注。

### F6 频繁更换审计机构 / 非标审计意见
审计报告为保留意见、无法表示意见或强调事项段涉及持续经营，或近三年更换会计师事务所。

### F7 在建工程长期挂账不转固
在建工程余额连年上升但迟迟不转固定资产，可能用于沉淀虚增资金。

### F8 勾稽关系异常
- 资产负债表不平（极少数低级错误）
- 折旧摊销与固定资产规模明显不匹配
- 利润表中"营业利润 + 营业外收支"与利润总额对不上

### F9 管理层与治理信号
实控人高比例股权质押（>70%）、高管密集离职、控股股东资金占用、被立案调查。

### F10 材料内部矛盾（授信场景）
申请材料中：报税收入与财报收入差距大、银行流水与账面营收不匹配、购销合同金额与账期不合理、 Different材料之间同一数据不一致。

## 输出要求

模式B输出 = 风险评分卡（低/中/高）+ 红旗明细表（编号、触发数据、依据）+ 建议补充核验项 + 免责声明。
未命中的红旗不列出；数据不足无法判断的条目列入"待补充资料"。
